# Prebuilt ESP32-S3 firmware

These files are regenerated automatically after every successful
`./tools/build.sh`.

[Main README](../README.md) | [Instrucciones en español](../README-ES.md)

These files are regenerated by `tools/build.sh` for ESP32-S3 boards with at
least 4 MB flash.

| File | Offset | Purpose |
|---|---:|---|
| `bootloader.bin` | `0x0` | Second-stage bootloader |
| `partition-table.bin` | `0x8000` | Project partition table |
| `wifi-motion-rssi-s3.bin` | `0x10000` | Main application |
| `wifi-motion-rssi-s3-complete.bin` | `0x0` | Combined factory image |

Use the separate-image script to preserve NVS settings:

```bash
PORT=/dev/ttyACM0 ./firmware/flash-prebuilt.sh
```

Use the combined image only for a clean installation. It overwrites the NVS
range and removes saved Wi-Fi, administrator, detector, and Telegram settings:

```bash
PORT=/dev/ttyACM0 ./firmware/flash-factory.sh
```

Verify the package with:

```bash
cd firmware
sha256sum -c SHA256SUMS
```
